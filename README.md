# OptiVerseStudio-Staging

Test builds of OptiVerse Studio. The developers use them to check the update path before a release.

- These builds have no support. Do not install them.
- A test build has its own application identifier and its own update key. An installed release of OptiVerse Studio does not accept a package from this repository.
- The releases of OptiVerse Studio are in [OptiVerseStudio-Releases](https://github.com/OptiVerse-Technology-Ltd/OptiVerseStudio-Releases).
- The source code is not in this repository.
